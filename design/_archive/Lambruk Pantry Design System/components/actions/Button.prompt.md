Lambruk's action button — use for every CTA; Title Case labels, never sentence case.

```jsx
<Button variant="primary" size="lg">Shop Now</Button>
<Button variant="secondary" size="lg">Visit Our Cafe</Button>
```

Variants: `primary` (navy fill, the default CTA) · `secondary` (transparent, warm hairline border) · `accent` (gold fill, navy text — use sparingly, one per view) · `onDark` (paper fill for navy panels) · `onDarkOutline` (transparent with a translucent paper border, for a secondary CTA over photography) · `ghost` (text-only inline action, goes gold on hover).
Sizes `sm`/`md`/`lg` = 36/44/52px. Hover darkens the fill; press scales to 0.98. Pass `href` to render an anchor.
