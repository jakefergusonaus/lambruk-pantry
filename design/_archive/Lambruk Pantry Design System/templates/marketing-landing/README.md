# Template — Marketing Landing

Starting folder for a Lambruk landing page: hero over brand photography, the claim-chip bar,
a seasonal product trio and the newsletter band, all composed from design-system components.

Entry: `MarketingLanding.dc.html`. The design system loads via `ds-base.js` — in a consuming
project, point the `base` line in that file at the bound `_ds/<folder>` tree.
