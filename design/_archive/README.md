# Archived — superseded by design/design_handoff_website/

This folder (`Lambruk Pantry Design System/`) was the design source `design/DESIGN-TOKENS.md` was
originally extracted from. It's superseded by `design/design_handoff_website/`, the complete
8-page handoff package added 2026-08-20 — verified against this folder's tokens and mockups the
same day; see the corresponding entry in `design/DESIGN-TOKENS.md` for what changed, held, and
went missing in that pass.

Kept rather than deleted because most of its contents (fonts, illustrations, product photography,
the `components/`, `ui_kits/`, `sources/` subfolders) were untracked in git before this move — a
delete here would have been unrecoverable. Nothing in `design/design_handoff_website/` should be
read as extending or correcting against this folder going forward; treat it as historical only.
