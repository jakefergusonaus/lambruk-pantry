# Lambruk line illustrations

Hand-drawn line marks supplied by the client. 400×400 PNG, transparent background.
Two colourways per motif: `-gold` (gold-500 `#BF8C45`, for paper fields) and `-ink` (black, for reversed/one-colour use).

| Motif | Files | Suggested use |
|---|---|---|
| Seedling | `seedling-gold.png` `seedling-ink.png` | Provenance / "sourced deep from Australian soil" |
| Fruit bowl | `fruit-bowl-gold.png` `fruit-bowl-ink.png` | Made with real fruit, entertaining |
| Peach | `peach-gold.png` `peach-ink.png` | Preserves, jams, seasonal fruit |
| Australia | `australia-gold.png` `australia-ink.png` | Australian ingredients, stockist / wholesale |
| Preserve jar | `preserve-jar-gold.png` `preserve-jar-ink.png` | Small-batch, pantry staples |

Sizing: 48–96px beside proof-point copy, up to 160px as a section mark. Never tint the gold version to another hue; use the ink version and recolour with a CSS filter only if a single-colour reversed treatment is needed.
