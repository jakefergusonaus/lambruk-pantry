# Phase 2 — Multi-Source Design Ingestion

Read only the source adapters relevant to the supplied inputs.

## Process

1. Register source location, type, viewport/state coverage, and authority in `DESIGN_SOURCE_MANIFEST.md`.
2. Extract exact content, hierarchy, grids, spacing, typography, color, imagery, icons, controls, states, interactions, and responsive evidence.
3. Record whether each observation is explicit, derived, or unknown.
4. Identify commerce states absent from static designs: variants, sold out, sale price, quantity, validation, loading, empty, search, filter, cart, localization, app and error states.
5. Compare overlapping sources and list conflicts.
6. Ask the user to resolve material conflicts and approve inferred behavior.
7. Save `DESIGN_BRIEF.md` and `ASSET_MANIFEST.md`.

Do not treat generated HTML as production Shopify architecture. Do not invent unseen responsive or interactive behavior without labelling and confirming it.
