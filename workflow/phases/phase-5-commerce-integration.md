# Phase 5 — Commerce Functionality

The existing store and base theme define the functional contract. Preserve it unless a confirmed requirement changes it.

Verify implementation coverage for in-scope features:

- Menus, localization controls and predictive search
- Product media, option/variant selection, price/compare-at price, quantity, availability and product forms
- Selling plans, unit price, pickup, recipient or complementary-product features when already used
- Collection product grids, filters, sorting and pagination
- Cart drawer/page, updates, notes, errors, discounts and checkout handoff
- Customer-account entry points for the configured account mode
- Search, blog, article, pages, contact, policies and password storefront
- Markets, currencies, languages and translations
- App blocks, embeds, analytics/events, metafields, metaobjects and dynamic sources

Use real Shopify data and native platform primitives. Do not hard-code catalogue content or change store data to make the design easier.
