# HTML/CSS Source Adapter

For local files or generated prototypes:

- Inventory HTML, CSS, JavaScript, assets, fonts, dependencies and routes.
- Render it in a browser and capture known viewports/states.
- Inspect DOM hierarchy, computed styles, responsive rules and interactions.
- Preserve exact approved copy/assets while translating the implementation into Liquid, Shopify resources, sections, blocks and snippets.
- Do not copy framework runtime, generated class noise, hard-coded products/prices, inaccessible controls or prototype-only scripts into the theme.
- Record missing commerce/editor states and ask about them.
