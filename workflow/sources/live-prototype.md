# Live Prototype Source Adapter

- Confirm the user is authorized to use the site/design as a source.
- Capture route inventory, viewports and interactive states with browser tooling.
- Inspect DOM, computed styling, assets, network, console and responsive behavior when permitted.
- Download/reuse only assets the client is authorized to provide.
- Record dynamic or inaccessible behavior as unknown rather than inventing it.
- Translate the design into the selected Shopify theme architecture; do not scrape or clone backend behavior.
