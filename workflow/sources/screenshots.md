# Screenshot Source Adapter

- Record each image's route/state, viewport dimensions and device scale when known.
- Extract visible layout, content, type, color, spacing, media treatment and controls.
- Group desktop/mobile images of the same page and identify responsive changes.
- Treat interactions, hidden states, exact measurements, assets and data sources as unknown unless another source confirms them.
- Ask about navigation, variants, cart, search, filtering, dialogs, editor controls and missing responsive widths before implementation.
- Label every inferred decision in `DESIGN_BRIEF.md`.
